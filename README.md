🎮 Dashboard de Vendas de Assinaturas Xbox Game Pass
📖 Sobre o Projeto
Este projeto foi desenvolvido no Microsoft Excel com o objetivo de analisar o desempenho das vendas de assinaturas do Xbox Game Pass por meio de dashboards interativos.

A análise contempla diferentes tipos de planos, modalidades de assinatura, descontos concedidos e receitas geradas por complementos (add-ons), permitindo a criação de insights relevantes para suporte à tomada de decisão.

🎯 Objetivo
Transformar dados brutos de assinaturas em informações estratégicas através de indicadores de desempenho (KPIs), gráficos dinâmicos e segmentações de dados.
